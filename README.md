# phyloGNN

Graph Neural Network (GNN) for phylogenetic analysis.

## Overview

This project implements a GNN architecture for analyzing phylogenetic trees. The model learns from tree structures with node and edge features to make predictions on evolutionary relationships.

## Project Structure

- `mySimulation/` - Data simulation pipeline
  - Scripts for generating phylogenetic trees
  - Node and edge feature extraction
  - XML generation for tree structures

## Status

Currently under development. GNN architecture implementation in progress.

## Requirements

- Python 3.x
- R (for feature generation)
